# Imagen del catálogo

`product-card.png` es una ilustración sintética de producto para el ejemplo de entrada multimodal. Contiene el nombre Carrito, el ID P001, Auriculares Nube y el precio 69,90 EUR. No acredita stock, prestaciones ni garantía y no representa una oferta comercial.

Inspecciona cómo se incorpora a una petición en `examples/multimodal.py`.
